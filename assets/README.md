# Assets

This directory contains supporting assets for the presentation.

## Contents

Store the following types of files here:
- Images (`.png`, `.jpg`, `.svg`)
- Diagrams and charts
- Icons
- Videos or GIFs (if applicable)
- Other media files

## Organization

- Use descriptive filenames
- Consider organizing by slide or topic
- Optimize images for presentation (reasonable file sizes)

## Attribution

If using third-party assets, add attribution information here.
